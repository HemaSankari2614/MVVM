# 🌸 WPF MVVM Practice 🚀

✨ A C# WPF desktop application developed using the **Model-View-ViewModel (MVVM)** architectural pattern. This project demonstrates separation of UI, business logic, and data using data binding and commands.

## 🛠️ Technologies Used

- 💻 C#
- 🎨 WPF
- 🧩 XAML
- 🏗️ MVVM Architecture
- 🔗 Data Binding
- ⚡ ICommand

## 📚 Concepts Practiced

- 🏛️ Model, View, and ViewModel
- 🔄 Data Binding
- 📢 PropertyChanged Notification
- 🎯 ICommand and Commands
- 🔐 Separation of Concerns
- ♻️ Code Reusability

## 🎯 Learning Objectives

- 🚀 Understand the MVVM design pattern.
- 🧠 Separate UI and business logic.
- 🔗 Implement data binding between View and ViewModel.
- 🛠️ Improve code maintainability and reusability.

## 🌟 Purpose

This project serves as a learning reference for implementing the MVVM pattern in WPF applications.



💖 **Developed for learning and practicing WPF MVVM concepts.**
